## Tagline

Turn one JSON file into a design system, components, screens and a prototype in Figma.

## Description

Dropkit builds your design in the open Figma file from one JSON file.

Tick what you want to build, then drop or paste the file:

- Design system: colour, spacing, radius and size variables, with light and dark modes; text, gradient and effect styles
- Components: variants and properties (text, show/hide, swap)
- Screens: frames that use your components and variables
- SVGs: icons and graphics as editable vectors
- Prototype & animations: links between screens, smart animate and other transitions

The plugin checks the file before it builds and explains every problem in plain words. A broken item is skipped and listed; everything else is still built. Running the same file again doesn't duplicate anything.

Write the JSON by hand, export it from your own tools, or have any AI write it: the plugin gives you instructions to copy and paste into the AI you already use.

Good to know:

- No account, no AI inside, and no internet connection. Nothing you drop in is sent anywhere.
- On Figma's free plan, colours are built with one mode only, because Figma allows one mode per collection on that plan.
- Fonts in your file must be installed on your computer.
