# Dropkit

A plugin for Figma that builds a design from a JSON file. Write the file yourself or have any AI write it. No AI inside the plugin.

**Start here:** `PROMPTS.md`, the step-by-step prompts for Claude Code.

| Path | What it is |
| --- | --- |
| `PROMPTS.md` | Step-by-step prompts to paste into Claude Code, with a test after each step |
| `CLAUDE.md` | Project rules Claude Code reads by itself |
| `docs/FORMAT.md` | The JSON format rules, v0.1. Source of truth. |
| `examples/` | A correct example file and two broken ones for testing |
| `design/` | The plugin screens (open the .html files in a browser) and design notes |
| `instructions/AI-INSTRUCTIONS.md` | The text behind "Copy instructions" |
| `listing/` | Figma Community listing draft, privacy policy, review checklist |
| `HANDOFF.md` | The original idea and the lessons from the Nudge plugins |
| `reference/` | The old Nudge plugin code and mock Figma, for reference |
